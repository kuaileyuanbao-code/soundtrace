## 使用与环境

完整解压，双击“打开声迹.bat”，使用完毕双击“关闭声迹.bat”。运行目录建议预留 30GB 空间，需要 Windows x64、兼容 CUDA 12.8 的 NVIDIA 驱动及 Edge/Chrome；建议 8GB 显存、32GB 内存。

运行包包含 CPython 3.11.15、两套 Python 环境、七组模型目录、启动/停止脚本、文件校验器及组件许可。Text/Fast/Main 可用；Review 扩展依赖未配置。运行时使用包内模型，启动器设置离线模式。用户数据在使用后写入 app/jobs、app/voiceprints、app/logs。
